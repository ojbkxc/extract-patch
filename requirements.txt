# ---------- 使用须知 ----------
# 1. 本文件按 Python 3.13 编写，OCR 用的是新版 rapidocr 包。

#        from rapidocr_onnxruntime import RapidOCR
#    该旧包在 PyPI 上限定 Requires-Python <3.13，在 3.13 上装不上。
#    要用这份依赖，需把该脚本迁移到新包（改 3 行，详见 README）。
#    旧包同时还在用老版 PP-OCR 模型，新包是 PP-OCRv6，生僻字精度更高。
# 2. 若改用 Python 3.11 / 3.12，把上面 OCR 那组替换为：
#        rapidocr-onnxruntime==1.4.4
#        opencv-python==4.10.0.84
#    （去掉 numpy / opencv-python-headless 两行）其余保持不变。
